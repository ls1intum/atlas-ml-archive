# AtlasML archive

AtlasML is retired. This repository preserves the `atlas/` directory and its available Git history from [edutelligence](https://github.com/ls1intum/edutelligence) at commit `ecbe2bb00b91577aeffebfb760f4a167263f75d7`.

The code, documentation, and deployment configuration are preserved for historical reference and may refer to services or paths that no longer exist. See [AtlasML's README](AtlasMl/README.md) and [documentation](docs/README.md).

The AtlasML GitHub Actions workflows and pull request template lived outside `atlas/` and are preserved in [`ci-archive/`](ci-archive/), outside `.github/` so they do not run here. [`ci-archive/edutelligence-shared-config.diff`](ci-archive/edutelligence-shared-config.diff) records the AtlasML entries removed from edutelligence's shared configuration (CODEOWNERS, Dependabot, Renovate, labelers, and shared workflows). The imported history ends at `271ea14`, a subtree split of `atlas/` whose tree is identical to `atlas/` at `ecbe2bb`.
